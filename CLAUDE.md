# Claude Code Instructions for CanvasDaemon

Follow `docs/AI_HELPER_GUIDE.md`. The repo is a reusable Canvas course-building toolkit. Do not commit local secrets, generated pages, manifests, reports, backups, preview config, or downloaded Canvas files. Use the documented scripts for modules, pages, assets, quizzes, discussions, and previews. Preserve dry-run defaults and explicit Canvas write confirmation.

When running `scripts/review_course_content.py`, address automated findings where possible and leave content-accuracy checklist items marked for human review unless a human reviewer approves them.
