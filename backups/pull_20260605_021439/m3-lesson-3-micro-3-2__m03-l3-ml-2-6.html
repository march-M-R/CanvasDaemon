Before You Watch

Rows are truth. Columns are what the model said.

“The confusion matrix sounds intimidating. It is a 2x2 grid. Read row by column. Diagonal cells are right. Off-diagonal cells are where the model is failing.”

Concept Companion

Four cells. One glance.

The diagonal tells you what works. The off-diagonal tells you what to fix. The bigger off-diagonal cell is your iteration target.

True Class A, Predicted A

Top-left

True Class A, Predicted B

True Class B, Predicted A
