Why LLMs Make Stuff Up

They predict the next token. They do not know what is true.

Big Question

Why does a model that knows nothing produce something that sounds so right?

Before You Watch

There is no truth-checker inside.

“An LLM is trained to produce text that 'looks right.' There is no separate module verifying claims against reality. The model picks the most likely next token, not the most accurate one.”

Concept Companion

Three mechanical reasons for hallucination.

Hallucination is not a bug. It is a property of how the model works. Better models hallucinate less. Zero is not reachable from current architectures.

Sounds right

Plausibility

Each token is picked to fit the pattern. Pattern-fit and truth are not the same thing.

No database

No retrieval

The model does not have a fact database it queries. The 'facts' are encoded in weights.

No check

No verification

There is no internal step that compares the output against the world before returning it.

Compare

What the model produces vs what is true.

Three patterns that come out of LLMs that look authoritative and may be entirely fabricated.

Citations

Common failure mode

Author + year + title + journal pattern, sometimes invented

How to verify

Search the journal for the title directly

Code function names

Common failure mode

Plausibly named library/function, may not exist

How to verify

Run the code or check the library docs

Statistics

Common failure mode

A specific-sounding number with no source

How to verify

Find the original study, not a model quote of it

Apply

Play: Next Word Predictor

Ask an LLM for three sources on a niche topic. Look up each one. Count how many actually exist. Now you know the hallucination rate for that topic.
