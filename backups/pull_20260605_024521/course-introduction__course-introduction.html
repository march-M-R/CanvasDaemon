Game Instructions

How the game works

Step 1

Read

Each round shows a technology example and asks you to classify it.

Step 2

Choose

Select one of the four categories shown in the game.

Step 3

Learn

After each answer, read the feedback explaining why the answer is correct or incorrect.

Step 4

Score

At the end, review your score card, accuracy, streak, and performance badge.

Game Categories

The four answer choices

Category What it means in the game
Conventional Software A system that follows fixed programmed instructions, like a calculator or checkout system.
Rule-Based Automation A system that follows if/then rules to trigger an action, like a thermostat turning on heat.
Machine Learning AI A system that learns patterns from data to classify, recognize, predict, recommend, or translate.
Generative AI A system that creates new content, such as text, essays, images, code, or responses.

Game Features

What to look for while playing

Score & Streak

The dashboard tracks your current score, answer streak, best streak, and progress.

50/50 Lifeline

Use the lifeline once to remove two incorrect answer choices.

Score Card

At the end, the game gives you a score card with your accuracy and performance badge.

Game Reminder

Do not choose “AI” just because something feels modern.

Use the game feedback to understand whether the system is following fixed instructions, using rules, learning from data, or generating new content.
