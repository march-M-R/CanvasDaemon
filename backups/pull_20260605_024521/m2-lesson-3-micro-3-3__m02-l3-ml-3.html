Before You Watch

Leakage is invisible until you ship.

“The model uses information during training that would not be available in production. The accuracy numbers all look amazing. The production deployment falls apart. Leakage is the most expensive bug in applied ML.”

Concept Companion

Three places leakage hides.

Leakage is hard to find because it looks like good performance. The fix is to audit every feature against one question: 'would I have this value at prediction time?'

A feature recorded after the outcome

Future leakage

Number of follow-up appointments, post-event metadata. The model 'predicts' something it already knows.

The label or near-duplicate as a feature

Target leakage

The exam score being used to predict whether the student passes. Obvious in hindsight, easy to overlook in a wide dataset.

Test examples mixed into training

Contamination

Duplicate rows, time series with overlap, the same user in both sets.
