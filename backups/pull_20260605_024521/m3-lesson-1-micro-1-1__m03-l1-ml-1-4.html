The Three Forms of Every Prediction

Input. Label. Confidence. That is the whole output.

Big Question

What does a classifier actually return when you give it a new input?

Before You Watch

Three pieces, every time.

Every working classifier returns the same three things, in the same order. Once you can name them, you can read any prediction.

Concept Companion

Input. Label. Confidence.

The model takes an input that matches the kind of data it was trained on, returns one label from the fixed list you defined, and attaches a number describing how sure it is.

What you give it

Input

A photo, sound clip, sentence, or row of numbers. It must match what the model was trained on.

What it returns

Label

One label, drawn from the fixed list at training time. Never new categories.

How sure it is

Confidence

A number from 0 to 1. High confidence is not the same as correct.

Compare

Same prediction, different stories.

Two predictions can have the same label and look completely different to the person reading them. The confidence is what tells the story.

LabelConfidenceWhat it really means
Spam98%Move on. The filter is almost certainly right.
Spam52%Treat with suspicion. The model is essentially flipping a coin.
Spam99%Verify anyway if the consequence is serious. Confident wrong happens.
