Sample Balance and Sample Variety

Equal counts. Wide coverage. No shortcuts.

Big Question

Why does class balance matter as much as raw sample count?
Watch → Read → Apply

Before You Watch

Imbalanced data teaches a shortcut.

When one class has more samples than the other, the model discovers that 'always guess the bigger class' is right most of the time. That looks like accuracy. It is laziness.

Concept Companion

Balanced counts. Varied conditions.

Two requirements. Count and condition. Imbalanced counts create a shortcut. Identical conditions create overfitting.

Roughly equal

Count balance

Within 10% of each other. 30:30 is great. 60:10 is a bias factory.

Vary the photos

Condition coverage

Different angles and lighting inside each class. The variety is the lesson.

Don't pad with duplicates

Honesty in counts

Ten near-identical samples count as one for variety purposes.

Compare

What different ratios actually do.

Same training algorithm. Same model architecture. Different class ratios. Different models.

RatioApparent accuracyActual model behavior
30 : 30Reflects skillHas to actually distinguish the two classes
60 : 20Inflated by ~10%Quietly leans toward the bigger class when uncertain
50 : 5~90% from doing nothingHas not learned the smaller class at all

Apply

Play: Balance Scale

After your first capture pass, count your samples per class. If the ratio is worse than 60:40, capture more of the smaller class before you click train.
