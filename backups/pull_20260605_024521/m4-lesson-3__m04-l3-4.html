The Core Question

Fluent is not the same as factual.

Large language models are next-word predictors. They have no internal fact-checker. They produce fluent, confident, grammatically correct sentences that are sometimes entirely fabricated. The model has no idea which is which.

Animation of text being generated word by word

Hallucination Defined

Output that is fluent and confident but factually wrong or invented, produced by a model that has no way to know the difference.

How an LLM Actually Produces Text Click to expand or collapse this section.

Token by token

There is no fact-checker inside.

When an LLM generates a sentence, it does not start with a fact and write toward it. It generates one token at a time, each one based on what was most likely to come next in the training data.

1

Word or word-piece

Token

The model predicts one token at a time, based on the previous text and learned patterns.
2

Sounds right

Plausibility

The model picks tokens that make the text fluent and grammatical, not necessarily true.
3

Nothing checks

No truth model

There is no separate part of the model that verifies the output against real-world facts.

Key Point

When an LLM cites a paper, it is not retrieving from a database. It is producing a citation pattern that fits. Often the citation is real. Sometimes the authors exist but the paper does not. Sometimes the entire reference is invented.

Confidence vs Correctness Four combinations. Different responses.

Tone and truth are two separate axes. Reading them together is the only way to act responsibly on what a model returns.

Training Data Becomes Output

Three places where bias enters.

An LLM is trained on text scraped from the internet. Whatever patterns exist in that text become defaults the model reaches for. Stereotypes get amplified, not invented.

The Training Set

Books, articles, forums, code. Heavily weighted toward English and a small number of cultures. Heavily weighted toward the loudest voices on each topic.

Step 1

Representation gap

Some groups appear less in training data than others. The model produces lower-quality, vaguer output for them.

 →

Step 2

Stereotype reinforcement

Common stereotypes become default outputs. 'Nurse' defaults female; 'engineer' defaults male.

Step 3

Cultural framing

American examples, Western units, mostly-Anglophone perspective dominate.

Step 4

Stale information

The training cutoff is fixed. Recent events, current facts, and corrections after the cutoff are missing.

The Verify-First Habit

Four checks before you act on an LLM answer.

If an LLM output will be used in any consequential decision, it must be verified first. Confidence is not verification.

1

Step 1

Find the specific claims

Highlight every name, date, statistic, quote, and citation in the output.
2

Step 2

Check each independently

Search the original source. If the model cited a paper, find the paper.
3

Step 3

Watch for confident-and-wrong

The most dangerous outputs sound exactly like the most accurate ones. Verify anyway.
4

Step 4

Test with substitution

Ask the same question with a different name or background. Compare the answers. Differences reveal bias.

Result

A verified LLM output is useful. An unverified LLM output is a guess in a confident voice. Treat them differently.

Common LLM Misconceptions Open this section to review the traps.

Common beliefs that fall apart on contact with real data.

Myth

'It cited a source, so it must be real'

Reality

Models routinely produce citation-shaped strings for papers that do not exist. The pattern looks right. The paper is not real.

Myth

'It sounds confident, so it is right'

Reality

Confidence is a stylistic property of fluent text. The model uses the same confident tone for true and invented claims.

Myth

'Newer models do not hallucinate'

Reality

Every commercial model in 2024 hallucinates regularly, including the most capable ones. Better models hallucinate less, not zero.

Key Takeaways

What you should remember from Lesson 3

LLMs predict tokens, not truths. The model has no separate fact-checking step. It produces what sounds right next, not what is right.

Confidence is style, not evidence. The same confident tone is used for true and invented claims. Verify every specific claim that matters.

Bias in output traces back to training data. Underrepresented groups get lower-quality output. Stereotyped patterns get amplified.
