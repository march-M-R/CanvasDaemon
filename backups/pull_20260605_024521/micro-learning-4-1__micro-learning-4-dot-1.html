Concepts

Three terms to know

Token

A small piece of text, such as a word, part of a word, or symbol.

Context

The surrounding information the model uses to decide what fits next.

Probability

The model estimates which token is most likely to come next.

Key idea: An LLM generates language step by step. Each new piece of text becomes part of the context for the next prediction.

Open: Why this can create fluent but wrong answers

The model is very good at producing language that sounds natural. But natural language is not the same as verified truth.

If a wrong answer fits the language pattern well, the model may still generate it unless it has a way to check the answer against a reliable source.
