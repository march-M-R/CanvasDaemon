GAME GUIDE

How to Play the Duck Quiz Game

A quick guide to downloading the file, starting the game, and answering each AI question with confidence.

QUICK START

Read this before you play

The Duck Quiz Game is a short practice activity about artificial intelligence. Each question gives you a real-world example, and your job is to decide which AI category fits best.

Important: The game will not run directly from this instruction page. Use the button at the bottom to download the game file from Canvas. After it finishes, open the file from your computer.

Do not worry if you miss a question. The point is to practice noticing patterns, making a choice, and learning from the explanation after each answer.

SETUP

How to start the game

1

Download the file

Click the button at the bottom of this page. Canvas may show a preview first; use the download option so the file is on your device.

2

Find the file

Look in your Downloads folder unless your browser asks you to choose another location. The file should open in a web browser.

3

Start playing

Double-click the file or choose Open. If your browser asks for permission to open a local file, allow it so the game can load.

PLAYING THE QUIZ

What to do on each question

Read the example carefully

Each question describes something AI might do, such as recognizing an image, recommending a song, predicting a result, or generating text. Look for the main job the AI is doing.

Choose the best category

Some choices may seem close. Pick the answer that matches the most important part of the example, not just one word that appears in the question.

Use feedback to improve

After you answer, the game explains why the correct category fits. Read the explanation even when you get the question right.

Use the lifeline wisely

The lifeline removes two incorrect choices. Save it for a question where you can narrow the answer down but still feel stuck.

SUCCESS TIPS

How to think like an AI detective

Ask yourself: Is the AI recognizing something, making a prediction, recommending something, or creating something new?

Watch your streak: The score and streak at the top of the game show your progress. A wrong answer resets the streak, but it does not mean you failed the activity.

If the file will not open: Check your Downloads folder, try opening it in Chrome or Safari, and make sure you are opening the game file itself instead of only viewing it in Canvas.
