Structured and Unstructured Data

Two big shapes data takes. Each one comes with very different cleanup costs.

Big Question

“Why does cleaning data take longer than building the model?”

Concept Companion

Two shapes. Three categories.

Pure structured and pure unstructured sit at the ends. Almost every real dataset is somewhere in the middle, with optional fields and inconsistent formatting.

1

Rows and columns

Structured

Spreadsheets, SQL tables, sensor logs. Same schema every row. Easy to load, easy to compare.

2

Free-form content

Unstructured

Documents, photos, audio, video. No fixed schema. Length and shape vary wildly.

3

Loose schema

Semi-structured

JSON logs, partially-filled forms, API responses. Some structure, not enforced.

Key Insight

The shape of the data sets the timeline.

Structured data, already in rows and columns, is the fast lane. Unstructured data, text and images and audio, is the slow lane. Most projects underestimate the cleanup time because they assume their data is structured when it is not.
