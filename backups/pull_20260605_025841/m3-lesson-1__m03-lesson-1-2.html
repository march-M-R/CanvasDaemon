Real-World Story

The Not Hotdog story

In 2017, the HBO show Silicon Valley satirized AI with an app called 'Not Hotdog' that did exactly one thing: tell hotdogs from non-hotdogs. The joke landed because that is literally what a classifier does. A developer actually built the app and shipped it. Millions of downloads. By the end of this lesson, you will be able to explain why two classes, picked well, can be a real product.

Core Idea

Classification is sorting, supercharged.

A classifier takes an input and assigns it to one of a fixed set of categories. The skill is not the click of a button. The skill is choosing categories that make sense and gathering data that actually represents them.

A classifier is only as good as the data and the question behind it.

Key Takeaways

What you should remember

A classifier needs a small, fixed set of distinct classes to work well.

The hard part is data quality and class design, not the training step.

A model that works in the demo is not the same as a model that works in real life.
