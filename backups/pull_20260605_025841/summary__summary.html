Master Concept Map

The basic AI pipeline

Almost every AI example in this module can be understood using this simple flow: input enters, the model finds patterns, the system predicts something, and people must decide how to use the result.

1. Input

Text, image, sound, clicks, location, behavior, or sensor data.

 →

2. Pattern

The model compares the input to patterns learned from examples.

 →

3. Prediction

The system estimates a label, ranking, next word, score, or likely action.

 →

4. Output

A recommendation, route, caption, answer, classification, or decision support.

Critical thinking layer: After the output, the human still needs to ask: Is this correct? Is it fair? Is it current? Is it safe to use?

Responsible AI Checklist

Before trusting AI, ask these questions

1. What is the AI doing?

Is it classifying, recommending, predicting, recognizing, or generating?

2. What data might shape it?

Could the data be incomplete, biased, outdated, or not representative?

3. What could go wrong?

Could the output mislead, exclude, stereotype, over-rank, or hallucinate?

4. How should I verify it?

Use reliable sources, compare evidence, and check recent or high-stakes claims.
Open: AI or Not AI quick check

A tool is more likely to involve AI if it handles variation, learns from patterns, ranks options, predicts outcomes, recognizes input, or generates new content.

A tool is more likely to be simple automation if it follows the same fixed steps every time without learning or prediction.

Open: Hallucination red flags
  1. The answer gives very specific facts without sources.
  2. The answer sounds certain about something recent or uncertain.
  3. The answer includes suspicious quotes, names, statistics, or citations.
  4. The answer avoids saying “I do not know” when it should be uncertain.

Meme-Level Summary

AI is powerful, but “sounds right” is not the same as “is right.”

The smartest AI users are not the ones who accept every answer. They are the ones who know what to question.

Final Activity

AI Detective Challenge

Choose one AI system you used or encountered recently. Then answer the questions below.

Detective Question Your Response
What AI system did you choose? Example: TikTok feed, Google Maps, captions, chatbot, Face ID.
What input does it use? Text, image, sound, location, clicks, history, or behavior.
What output does it produce? Recommendation, prediction, ranking, caption, recognition, or generated answer.
What is useful about it? Explain how it helps someone save time, find information, create, navigate, or decide.
What is one reason not to trust it blindly? Bias, wrong context, outdated info, hallucination, overpersonalization, or incomplete data.

Submission goal: Show that you can identify an AI system, explain what it does, and evaluate it critically.
