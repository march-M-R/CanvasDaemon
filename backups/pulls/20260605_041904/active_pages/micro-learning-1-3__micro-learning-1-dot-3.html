Concept Companion

A practical ladder for thinking about AI capability.

The purpose of the tier ladder is not to rank tools as “good” or “bad.” It helps you describe what a system can actually do.

Tier 1

Classify

The system sorts an input into a category.

Example: Spam or not spam.

Tier 2

Predict or Recommend

The system estimates what is likely or ranks what may be useful.

Example: Netflix, Spotify, Google Maps.

Tier 3

Generate

The system creates new content from learned patterns.

Example: ChatGPT writing text or an image generator making art.

Tier 4

Act with Tools

The system uses tools or steps to complete a task with more independence.

Example: An AI agent planning, searching, drafting, and updating a file.

Why This Matters

Capability changes the risk.

AI Capability What it can do What to watch for
Classify Labels or sorts inputs Wrong labels, unfair patterns, false positives
Recommend Ranks choices or suggestions Influence, filter bubbles, over-personalization
Generate Creates new content Hallucinations, fake sources, misleading confidence
Act with tools Completes multi-step tasks using external systems Mistakes can have consequences beyond the chat window

Key point: The more an AI system can do, the more carefully people need to evaluate its output, limits, and consequences.

Mini Activity

Place the tool on the ladder.

For each example, identify the strongest visible AI capability. Some systems may use multiple capabilities, but choose the most visible one.

Quick Check

One question before you return.

A tool writes a new song lyric from a prompt. Which tier is most visible?

Reveal answer

Generate. The tool is creating new content from a prompt. It may use prediction internally, but the visible capability is generation.
