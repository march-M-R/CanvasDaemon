1. Multiple Choice, 1 point
Question: Which of the following best defines "data" for machine learning purposes?

Question: Which of the following is NOT data until it is captured?

Correct answer: C

3. Multiple Answer, 2 points
Question: Which three properties must something have to count as data a model can use?

B. Comparable across examples in the same format

D. Discovered by an expert
E. Stored in the cloud
