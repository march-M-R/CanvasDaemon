Auto-graded question types only

1. Multiple Choice, 1 point
Question: Why does a model that scores 99% on its training data and 60% on fresh data have a problem?
A. The training data is corrupted
B. It memorized the training examples instead of learning a generalizable pattern
C. The model is too small
D. The test data was leaked
Correct answer: B

2. Multiple Choice, 1 point
Question: Which set is used to compare two model versions and pick hyperparameters?
A. Training set
B. Validation set
C. Test set
D. Production set
Correct answer: B

3. Multiple Choice, 1 point
Question: Which set is touched exactly once, at the very end, for an honest accuracy report?
A. Training set
B. Validation set
C. Test set
D. The full dataset
Correct answer: C

4. Multiple Answer, 2 points
Question: Which of the following are signs of data leakage?
A. Test accuracy that is suspiciously high on a known-hard problem
B. A feature recorded after the outcome
C. The same rows appearing in both training and test sets
D. The model is too small
E. Preprocessing statistics computed using the test set
Correct answer: A, B, C, E

5. True or False, 1 point
Question: It is safe to compute scaling statistics (like a feature's mean) using both training and test sets together.
Correct answer: False

6. Multiple Choice, 1 point
Question: A model scores 72% on training and 70% on test. What is the most likely issue?
A. Overfitting
B. Underfitting
C. Data leakage
D. Healthy generalization with weak features
Correct answer: D

7. Multiple Choice, 1 point
Question: Which of the following is an example of target leakage?
A. Including the final exam score as a feature when predicting whether a student passes the final exam
B. Including the student's homework completion rate
C. Including the student's attendance rate
D. Including the day of the week the course meets
Correct answer: A

8. Multiple Choice, 1 point
Question: What is the typical split for a small training dataset?
A. 100% training, 0% test
B. 50% training, 50% test, no validation
C. 70% training, 15% validation, 15% test
D. 10% training, 90% test
Correct answer: C

9. True or False, 1 point
Question: Every time you check the test set and use it to make a decision (like retraining), the test set becomes less honest as a final accuracy measure.
Correct answer: True

10. Multiple Choice, 1 point
Question: A team predicts hospital readmission and includes "number of follow-up appointments scheduled" as a feature. What is wrong with this?
A. The model is too small
B. The feature is leaked from the future, since follow-up appointments are scheduled in response to the readmission outcome
C. The feature is unethical to collect
D. Nothing is wrong
Correct answer: B

11. Multiple Choice, 1 point
Question: When evaluating a model, which number is the most honest measure of real-world performance?
A. Training accuracy
B. Validation accuracy after 10 retraining rounds
C. Test accuracy on data the model has never seen
D. The model's confidence on the first prediction
Correct answer: C

12. Multiple Answer, 2 points
Question: Which of the following are reasons to use a time-based train/test split instead of random?
A. The model will be used to predict future events from past data
B. The data is a time series and random splits would let future information leak into training
C. The data has natural temporal ordering
D. The data is unstructured
Correct answer: A, B, C
