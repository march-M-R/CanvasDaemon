1. Multiple Choice, 1 point
Question: Why is testing on the training data nearly meaningless?
A. The data is too small
B. The model has already seen those examples and memorized them
C. The test takes too long
D. The labels are wrong
Correct answer: B

2. Multiple Choice, 1 point
Question: In a confusion matrix, what does the diagonal show?
A. Correct predictions (where actual class matches predicted class)
B. Incorrect predictions
C. Random predictions
D. Predictions with high confidence only
Correct answer: A

3. Multiple Choice, 1 point
Question: What is a False Negative?
A. The model said yes and was wrong
B. The model said no and was wrong (it missed something it should have caught)
C. The model said yes and was right
D. The model said no and was right
Correct answer: B

4. Multiple Choice, 1 point
Question: Which of the following best describes a False Positive in a smoke detector?
A. House fire missed
B. Alarm at 2 AM with no fire
C. Detector working correctly
D. Detector turned off
Correct answer: B

5. Multiple Answer, 2 points
Question: Which of the following are true about confidence scores?
A. A 99% confident wrong answer is a different problem from a 60% confident right answer
B. High confidence guarantees correctness
C. Confidence and correctness are two separate axes worth reading together
D. Confident-and-wrong cases often point to a shortcut the model has learned
E. Confidence is only useful for spam filters
Correct answer: A, C, D

6. True or False, 1 point
Question: The minimum number of fresh test samples per class you should use before claiming any accuracy figure is 10.
Correct answer: True

7. Multiple Choice, 1 point
Question: A model has 9 True Positives, 1 False Negative, 5 False Positives, and 5 True Negatives. What does this pattern suggest?
A. The model over-predicts the positive class
B. The model is balanced
C. The model under-predicts the positive class
D. The model is broken
Correct answer: A

8. Multiple Choice, 1 point
Question: After testing, which off-diagonal cell of the confusion matrix should you target for the next iteration?
A. The smallest one
B. The largest one (it shows the model's weakest area)
C. The one closest to zero
D. Random
Correct answer: B

9. Multiple Choice, 1 point
Question: Which is the more honest test for a model?
A. Re-running the model on training data
B. Running the model on fresh samples that were not part of training
C. Asking the user
D. Counting only wins
Correct answer: B

10. True or False, 1 point
Question: A 95% confident wrong prediction is usually safer than a 60% confident right one, because confidence is what matters most.
Correct answer: False

11. Multiple Choice, 1 point
Question: Which question should you ask BEFORE accepting any accuracy number?
A. Was the test set the same as the training set?
B. Was the test set held out and never used during training?
C. Was the model trained on a fast computer?
D. Was the model the largest one available?
Correct answer: B

12. Multiple Answer, 2 points
Question: Which of the following are signs of dishonest testing?
A. Reporting accuracy on the training set
B. Testing only one sample
C. Logging only the wins
D. Held-out fresh test set with documented protocol
E. Testing on a small number of carefully chosen examples
Correct answer: A, B, C, E
