Google Colab, Drive, Gemini, and Recovery

One reliable workflow for opening notebooks, saving progress, handling project files, using AI safely, and recovering when something breaks.

Before you begin

Use a laptop or desktop. Colab may open on a phone or tablet, but uploading files, managing cells, debugging, and exporting artifacts are substantially harder. If you lack suitable access, contact your instructor before beginning the notebook work.

Open, save, and name your notebook

  1. Download the supplied .ipynb file from Canvas.
  2. Open Google Colab and choose File → Upload notebook.
  3. Choose File → Save a copy in Drive.
  4. Rename the Drive copy using the exact filename shown on the activity page.
  5. Continue in the same Drive copy throughout the module.

Run notebooks reliably

Predict first

Read each cell and predict what it will produce before pressing play or using Shift+Enter.

Run in order

Begin at the top. Later cells often depend on variables, functions, or files created earlier.

Verify from a clean state

Before finishing, use Runtime → Restart session and run all. A notebook that only works out of order is not finished.

Upload and export project files

Upload inputs

Open Colab’s folder panel, choose Upload, and select the supplied CSV or JSON. Keep filenames unchanged because notebook code refers to them exactly.

Download outputs

After the notebook confirms that an artifact was saved, find it in the folder panel, open its menu, and choose Download. Store it in your Phase 2 portfolio folder.

Use Gemini as a coach - not a replacement

Ask for explanations, traces, hints, test cases, or critique. Do not ask Gemini to replace the complete notebook. Run or inspect every suggestion and record what you accepted, changed, or rejected.

Useful prompt

I am learning Python. Explain this code one line at a time. Trace it using the input I provide. Give one hint before suggesting a change. Do not replace the entire solution. End with one question that checks my understanding.

Privacy boundary

Never enter names, passwords, private files, school records, or sensitive personal information. Use only fictional or course-provided examples. If Gemini is unavailable in your managed account, use the approved AI route supplied by your instructor; if no approved AI route is available, complete the written prediction, code trace, testing, and reflection, then notify your instructor.

Recovery checklist

  1. Save a fresh Drive copy before making a major repair.
  2. Check that required CSV or JSON files are uploaded with exact filenames.
  3. Use Runtime → Restart session, then run cells from the top.
  4. Read the first error - not only the final error.
  5. Compare the damaged section with the supplied checkpoint copy.
  6. If recovery would erase completed work, keep the damaged copy and ask your instructor for help.
