Why One Bad Label Can Ruin a Model

Labels are the model's truth. Wrong labels become learned bias.

Big Question

“How does a 1 percent labeling error become a systematic problem?”

Concept Companion

Random noise vs systematic bias.

Not all bad labels are equal. A handful of random errors barely move the needle. A handful of consistent errors becomes the model's worldview.

1

Small handful of errors, no pattern

Random noise

Barely affects the model. With enough good labels, it averages out. Tolerable.

2

Errors all in one direction

Systematic bias

The model learns the bias as the rule. Untolerable. Has to be fixed at the labeling step, not the model step.

3

Two labelers disagreed and the conflict was not resolved

Disagreement

Pure noise. The model gets two different answers for similar examples. Resolve before training.

Key Insight

The model believes the labels.

Supervised learning trusts the label as ground truth. If the label is wrong, the model has no way to know. If the labels are systematically wrong in one direction, the model absorbs that direction as truth.

Compare

Where bad labels come from.

Bad labels are not random. They come from specific sources. Knowing the source tells you how to fix the data.

Source

Single labeler under speed pressure

Type of error

Consistent errors

Fix

Add more labelers, slow the pace, raise the rate

Source

Vague guidelines

Type of error

Disagreement on borderline cases

Fix

Write clearer guidelines with worked examples

Source

Labels copied from a buggy system

Type of error

Whole categories shifted wrong

Fix

Re-label the data; do not 'fix' downstream

Source

Labels reflect past human bias

Type of error

Systematic discrimination

Fix

Audit per group, consider de-biasing or different label source
