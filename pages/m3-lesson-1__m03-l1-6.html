The Core Question

Before we open the tool, we need to know what a classifier returns.

A machine may be fast, automated, or impressively accurate. But classifying means more than producing a label. It means assigning an input to one of a fixed set of categories, and reporting how confident it is.

Animated brain activity representing classification thinking

Classifier Defined

A function that maps an input to one of a fixed set of categories, along with a confidence score.

The Three Pieces of Every Prediction Click to expand or collapse this section.

Input → Label → Confidence

A classifier returns three things, in order.

When you give a trained model a new input, this is what comes back. Always these three. Nothing else.

1

What you give the model

Input

A photo, a sound clip, a sentence, or a row of numbers. It must match the kind of data the model was trained on.
2

What the model returns

Label

One label, drawn from the fixed list you defined at training time. The model never invents new categories.
3

How sure the model is

Confidence

A number between 0 and 1, often shown as a percent. High confidence is not the same as correct.

Key Point

Read both the label and the confidence on every prediction. A confident wrong answer is a different problem from an unsure right answer.

Classifier vs Generator Compare a classifier with a generative model.

Both are AI. Both produce outputs. But they answer very different questions, and they fail in very different ways.

Compare on Classifier: Sort Into Bins Generator: Create New Content
Example Input: photo of a fruit Input: 'Write a poem about an avocado'
Outcome Output: 'ripe' (87% confident) Output: a brand new poem
Note Same fruit, same conditions, same answer. Different output every time it is asked.
Why it matters The classifier picks one of the categories you defined. It cannot say 'I don't know.' It cannot create a new label. It can only assign the input to a class it was trained on. A generative model produces new text, images, or audio that did not exist before. Same prompt, different output. Fluent does not mean correct. Useful does not mean accurate.

Common Beginner Mistakes Open this section to review the traps.

Common beliefs that fall apart on contact with real data.

Myth

More data is always better

Reality

Diminishing returns is real. After about 30 samples per class, variety matters more than volume. Capture different conditions, not more of the same.

Myth

High accuracy means it works

Reality

A model that scores 95% on its training data can fail completely on fresh photos. Always test on samples the model never saw.

Myth

The demo is the project

Reality

A model that works under your webcam at your desk is not the same as a model that works in someone else's hands. The Model Card is the real deliverable.

Key Takeaways

What you should remember from Lesson 1

A classifier assigns an input to one of a fixed set of categories. It cannot invent new ones, and it always returns a confidence number along with the label.

The deliverable this week is a trained two-class image classifier plus a one-page Model Card. The Model Card is what makes the work real.

The mindset: a model that works in the demo is not the same as a model that works in real life. Build it. Break it. Document it.
