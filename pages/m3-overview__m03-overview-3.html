Module Mindset

Build it. Break it. Document it.

This week is not about getting a model to work in a demo. It is about getting a model to work in the wild, knowing where it fails, and writing that down clearly enough for a stranger to trust you.

Learning Outcomes

What you will be able to do

Outcome 1

Build a working 2-class image classifier in Teachable Machine with at least 30 balanced samples per class.

Outcome 2

Diagnose model mistakes using a confusion matrix, false positives, false negatives, and confidence scores.

Outcome 3

Iterate on a model by adding targeted training data to fix its most common failure modes.

Outcome 4

Recognize the limits of a 'demo-ready' classifier and describe edge cases where it should not be trusted.

Outcome 5

Document your model in a one-page Model Card that a non-technical reader could understand.

Module Goal

Ship a trained 2-class classifier and an honest Model Card.
